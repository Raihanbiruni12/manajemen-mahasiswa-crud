**TaskMaster** (atau ganti dengan nama aplikasi Anda) adalah aplikasi mobile berbasis CRUD (Create, Read, Update, Delete) yang dikembangkan menggunakan framework Ionic dan Angular. Aplikasi ini dirancang untuk mendemonstrasikan pengelolaan data secara efisien pada perangkat seluler.

## 🌟 Fitur Utama (CRUD)
- **Create (Tambah):** Pengguna dapat menambahkan data tugas baru beserta deskripsi dan tenggat waktu.
- **Read (Tampil):** Menampilkan daftar tugas dalam antarmuka *list* yang rapi dan responsif.
- **Update (Ubah):** Memungkinkan pengguna untuk mengedit informasi tugas atau menandainya sebagai selesai.
- **Delete (Hapus):** Menghapus data tugas yang sudah tidak diperlukan dari sistem.

## 🛠️ Teknologi yang Digunakan
- **Frontend Framework:** Angular
- **UI Toolkit:** Ionic Framework
- **Native Runtime:** Capacitor
- **Bahasa:** TypeScript, HTML, SCSS
