# 🎓 Manajemen Data Mahasiswa (Ionic CRUD Application)

![Ionic](https://img.shields.io/badge/Ionic-%233880FF.svg?style=for-the-badge&logo=Ionic&logoColor=white)
![Angular](https://img.shields.io/badge/angular-%23DD0031.svg?style=for-the-badge&logo=angular&logoColor=white)
![TypeScript](https://img.shields.io/badge/typescript-%230074C1.svg?style=for-the-badge&logo=typescript&logoColor=white)

**Manajemen Data Mahasiswa** adalah aplikasi mobile berbasis CRUD (Create, Read, Update, Delete) yang dibangun menggunakan framework Ionic dan Angular. Aplikasi ini dirancang untuk mempermudah pencatatan, pengelolaan, dan pencarian data profil mahasiswa secara efisien melalui perangkat seluler maupun web.

## 🌟 Fitur Utama
- **Create (Tambah Data):** Form input terstruktur untuk mendaftarkan mahasiswa baru dengan detail mencakup Nama Lengkap, NIM, Jurusan, Email, dan Alamat.
- **Read & Search (Tampil & Cari Data):** Menampilkan daftar mahasiswa yang telah tersimpan secara responsif. Dilengkapi dengan fitur pencarian *real-time* berdasarkan Nama, NIM, Jurusan, atau Email[cite: 3].
- **Delete (Hapus Data):** Fungsionalitas manajemen data yang mudah, memungkinkan pengguna untuk menghapus rekaman data yang tidak lagi diperlukan hanya dengan satu ketukan[cite: 3].

## 🛠️ Teknologi yang Digunakan
- **Frontend Framework:** Angular
- **UI Toolkit:** Ionic Framework
- **Native Runtime:** Capacitor
- **Bahasa Pemrograman:** TypeScript, HTML, SCSS
